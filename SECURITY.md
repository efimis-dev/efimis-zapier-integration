# Security Policy

## Reporting a vulnerability

Please do not disclose suspected vulnerabilities in a public issue, discussion, or
pull request.

Report them privately to `connections@efimis.com` with the subject
`Efimis Zapier integration security report`. Include:

- A description of the issue and its potential impact.
- Reproduction steps or a minimal proof of concept.
- The affected integration version or commit, if known.
- Any suggested mitigation and whether the issue has been disclosed elsewhere.

Do not include live credentials, access tokens, webhook secrets, or customer data.
Use synthetic test data and an Efimis sandbox wherever possible.

Efimis will acknowledge the report, investigate it, and coordinate remediation and
disclosure with the reporter. Response and resolution timing depends on severity
and reproducibility.
